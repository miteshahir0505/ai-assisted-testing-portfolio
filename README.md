# AI-Assisted Testing Portfolio

Hi, I'm Mitesh Ahir, a QA / manual tester with 10+ years of experience in web applications, API testing, e-commerce.
This repo shows how I use AI to test faster while still applying my own judgment.

**Rule I follow:** every AI output is reviewed by me. Each project documents what the AI got wrong and what I corrected.

## Projects
| # | Project | What it shows |
|---|---------|---------------|
| 1 | [Test case generation](./01-test-case-generation) | Same prompt run across 4 AI tools, compared, merged into 29 cases, all executed on the live app |
| 2 | [Prompt library](./02-prompt-library) | 8 reusable prompts for testers, with real worked examples |
| 3 | [Bug reports & exploratory testing](./03-bug-reports-exploratory) | A real bug report from an actual finding, plus AI-generated exploratory charters |
| 4 | [Manual to automation](./04-manual-to-automation) | 3 executed manual test cases converted into Playwright scripts |
