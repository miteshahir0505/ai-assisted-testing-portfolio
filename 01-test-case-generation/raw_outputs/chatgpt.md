# Assumptions
1. A registered user has a valid username and password.
2. There is a known locked-out user account available for testing.
3. The inventory page is the expected landing page after successful login.
4. The application has a username field, password field, and login/submit action.
5. “Saved credentials” means browser password-manager/autofill credentials.
6. No assumptions are made about CAPTCHA, MFA, password-reset, account-unlock, or session-timeout functionality because they are not mentioned in the story.
