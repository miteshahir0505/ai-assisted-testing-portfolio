# Assumptions
**System Under Test:** Testing is executed live against [https://www.saucedemo.com/](https://www.saucedemo.com/).

**Error Message Wording:** Expected error message strings match the exact UI error badges implemented by Swag Labs (Epic sadface: ...).

**Session Behavior:** Unauthenticated access attempts to [https://www.saucedemo.com/inventory.html](https://www.saucedemo.com/inventory.html) trigger client-side route protection.
